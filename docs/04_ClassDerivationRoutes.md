# ROLC クラス派生ルート仕様書 (Class Derivation Routes Specification)

## 概要
本ドキュメントは、ROLC（Record of Legends Character）における 1次〜4次クラスおよび Ex クラスの公式階層派生ルールを定義した仕様メモである。

---

## 1. 1次クラス ➔ 2次クラス 派生ルート

| 1次クラス | 派生可能な 2次クラス |
| :--- | :--- |
| **ソルジャー (SOL)** | ブレイブハート (BRV), センチュリオン (CEN) |
| **シーフ (THF)** | レンジャー (RNG), フェンサー (FNC) |
| **ウォリアー (WAR)** | フェンサー (FNC), グラディエーター (GLD) |
| **ナイト (KNT)** | グラディエーター (GLD), クルセイダー (CRD) |
| **クレリック (CLC)** | クルセイダー (CRD), ウォーロック (WLK) |
| **メイジ (MAG)** | ウォーロック (WLK), ソーサラー (SOR) |
| **エンチャンター (ENC)** | ソーサラー (SOR), レンジャー (RNG) |

---

## 2. 2次クラス ➔ 3次クラス 派生ルート

| 2次クラス | 派生可能な 3次クラス |
| :--- | :--- |
| **ブレイブハート (BRV)** | ロード (LOR), コンカラー (CNQ) |
| **センチュリオン (CEN)** | ロード (LOR), コンカラー (CNQ) |
| **レンジャー (RNG)** | エレメンタリスト (ELM), アサシン (ASN) |
| **フェンサー (FNC)** | アサシン (ASN), ベルセルク (BSK) |
| **グラディエーター (GLD)** | ベルセルク (BSK), ジェネラル (GRL) |
| **クルセイダー (CRD)** | ジェネラル (GRL), セイント (SNT) |
| **ウォーロック (WLK)** | セイント (SNT), ウィザード (WIZ) |
| **ソーサラー (SOR)** | ウィザード (WIZ), エレメンタリスト (ELM) |

---

## 3. 3次クラス ➔ 4次クラス 派生ルート

| 3次クラス | 派生可能な 4次クラス |
| :--- | :--- |
| **ロード (LOR)** | ヒーロー (HRO) |
| **コンカラー (CNQ)** | ヒーロー (HRO) |
| **アサシン (ASN)** | 忍者 (NIN), スペルマスター (SPM) |
| **ベルセルク (BSK)** | ソードマスター (SDM), 侍 (SAM) |
| **ジェネラル (GRL)** | 侍 (SAM), パラディン (PLD) |
| **セイント (SNT)** | パラディン (PLD), セージ (SAG) |
| **ウィザード (WIZ)** | セージ (SAG), スペルマスター (SPM) |
| **エレメンタリスト (ELM)** | スペルマスター (SPM), 忍者 (NIN) |

---

## 4. Exクラス (共通)

全クラス共通で以下の Ex クラスを選択可能：
- **マーシナリー (MRC)**
- **ドラグーン (DRG)**
- **ベネラー (VEN)**
- **クロノマスター (CRN)**
- **モンク (MNK)**
